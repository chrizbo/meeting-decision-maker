# False Decision Trap

This case tests whether the model avoids turning a strong individual preference into a decision.

If the model captures a forming decision, it should make the lack of consensus clear. Alex has a strong preference, but Mina challenges the evidence and Alex explicitly says he is not asking for approval today.

## Should Not Emit

- No accepted rewrite decision.
- Any forming decision should say there is no consensus yet.
- No risk from vague annoyance.
- No action item unless an owner/timing appears.
