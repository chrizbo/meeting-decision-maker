The decision layer for Zoom

Zoom records what happened. Room Clarity helps the room decide what happens next.

Live decision board

Room Clarity watches transcript cues and keeps a visible board of candidate decisions, risks, and action items for the host to confirm.

In-meeting challenge

Built-in decision-support agents flag assumptions, failure modes, and weak arguments while the host still has a chance to ask a better question.

Host-in-the-loop control

The host can confirm, edit, dismiss, or escalate what the AI finds, so the record reflects team intent instead of raw model output.

Shared artifact

The host can share the meeting board in Zoom or open a browser dashboard when the group needs a visible working surface.

Reviewed brief

After the conversation, the host can exclude noisy items, promote useful prompts, and copy a concise brief grounded in transcript evidence.

GitHub handoff

Connect a repository during setup and Room Clarity will surface related issues on the live board, propose GitHub issues for each confirmed decision and action, and upload the meeting transcript as a pull request — all confirmed by the host before anything is written.

Install

Add Room Clarity to Zoom.

  1. Install or request approval. Open the Room Clarity Zoom Marketplace listing. If your organization requires approval, request it from your Zoom administrator.
  2. Launch it from Zoom Apps. Start a Zoom meeting, open the Apps panel, and choose Room Clarity. The app creates a meeting board for that session.
  3. Share the board with the room. Use the app surface directly or open the dashboard in a browser and screen-share it when the group needs a shared artifact.
  4. Connect GitHub (optional). In the Meeting Runway step, connect your GitHub account and bind a repository. Room Clarity will search for related issues during the meeting and propose issues and a transcript pull request in the brief step.
  5. Review before relying on outputs. Generated decisions, prompts, and GitHub proposals are assistance only. The host should confirm records, exclude anything noisy, and approve each GitHub write before it happens.
